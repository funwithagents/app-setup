# Autostart

**Status:** Done

Implements `specs/autostart.md`: the autostart section, the `--start` / `--no-start` flags and `starts_at_launch`, so every app that starts its session at launch does it the same way. Leaves the app's own Start, and what it shows of blockers, to the app.

## Scope

- `src/module_setup/autostart.py` — `AutostartContract`, `autostart_section`, `add_start_arguments`, `starts_at_launch`.
- `tests/test_autostart.py` — the contract, the decision, the flags.
- `tests/ui/test_panels.py` — the section drawn as a checkbox.
- `specs/autostart.md`, `specs/_index.md`, `plans/_index.md`, `AGENTS.md` (the map's row), `README.md` (the usage).

## Steps

1. Write the contract as a small class holding its default and title; `autostart_section` wraps it in a `Section`.
2. `add_start_arguments`: one `BooleanOptionalAction` argument, default `None`.
3. `starts_at_launch`: the flag, else the saved config at the section found by its contract, else its default.
4. Tests, spec, map, README.
