# Autostart

**Status:** Done

Implements `specs/autostart.md`: an app declares whether it starts its session at launch, the user's choice is kept in the folder's `launch.json` apart from the config, the Setup panel draws it, and `--start` / `--no-start` override it for one launch. Leaves the app's own Start, and what it shows of blockers, to the app.

## Scope

- `src/module_setup/app.py` — `App.autostart`; `AppModel.autostart()`, `set_autostart(on)`.
- `src/module_setup/folder.py` — `launch_path`, `read_launch`, `save_launch`.
- `src/module_setup/autostart.py` — `add_start_arguments`, `starts_at_launch`.
- `src/module_setup/ui/panels.py` — the checkbox next to Save, Revert and Reset, saved at once.
- `tests/test_autostart.py`, `tests/ui/test_panels.py`.
- `specs/autostart.md`, `specs/app.md`, `specs/config-folder.md`, `specs/ui.md`, `specs/_index.md`, `plans/_index.md`, `AGENTS.md` (the map's row), `README.md` (the usage).

## Steps

1. A first version kept the choice in the config, as a section module-setup provided (`autostart_section`); replaced before review by `launch.json`, so the config stays the app's own sections (see the spec's open question 1).
2. `App.autostart`, the folder's `launch.json`, the model's `autostart()` / `set_autostart()`, not refused while the config is locked.
3. `add_start_arguments`: one `BooleanOptionalAction` argument, default `None`; `starts_at_launch`: the flag, else `launch.json`, else the default.
4. The Setup panel's checkbox for an app with autostart.
5. Tests, specs, map, README.
