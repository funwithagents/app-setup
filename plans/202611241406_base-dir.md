# Relative paths: the contract carries the app's folder

**Status:** Done

Implements `specs/module-contract.md` ("Relative paths: `base_dir`"): `check_setup`, `prepare`, `options` and `probe` take a `base_dir` keyword, module-setup passes the app's folder, and `check_contract` refuses a function that does not take it. Leaves to each library resolving its own paths against it.

## Scope

- `src/module_setup/contract.py` — the `SetupContract` signatures; `check_contract` checks the keyword.
- `src/module_setup/app.py` — `AppModel` passes its folder to the four functions.
- `tests/fakes.py`, `tests/test_contract.py`, `tests/test_app.py` — the fakes take it; a function without it is a breach; the model hands its folder.
- `specs/module-contract.md`, `specs/config-folder.md`.

## Steps

1. Found by the libraries' demos: Check resolved a relative path against the working directory while the session resolved it against the folder (a wica demo changed its working directory to work around it).
2. The keyword on the Protocol, the check, the model.
3. Tests and specs.
