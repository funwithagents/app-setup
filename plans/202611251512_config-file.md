# Config file

**Status:** Done

Implements the settled behavior in `specs/config-file.md` (all of it, "Changes to the other specs" included). Delivers a single config file as a second source of the config (`ConfigFile`), a one-section app declared `bare` (its config the library's own document), the command line every app shares (`--folder` | `--config`, `--env`), an app running a file (the Setup panel read-only, its session started at launch) and a config app editing one (`config_page`). Leaves out what the spec defers: a config app creating a missing file, watching the file, the file's JSON shown folded instead of the read-only form.

## Scope

- `src/app_setup/config_file.py` — new: `ConfigFile`, `ConfigFileError`
- `src/app_setup/folder.py` — `ConfigFolder(..., env_path=None)`; `base_dir`, `writable`, `resettable`
- `src/app_setup/app.py` — `App(bare=...)` (refused with more than one section); `AppModel(app, source, ...)`, `source`, `editable`; the bare wrapping in `saved_config`, `save`, `reset`; `reset` refused for a source without a default; `path` is `source.base_dir`
- `src/app_setup/autostart.py` — `starts_at_launch`: from a file, the session starts unless `--no-start`
- `src/app_setup/launch.py` — new: `add_config_arguments`, `open_source`, `add_config_app_arguments`, `open_config_app`
- `src/app_setup/ui/form.py` — `render_section(..., readonly=False)`: every field drawn, none editable, no listener, no list button
- `src/app_setup/ui/panels.py` — the read-only Setup panel (the file's line, the read-only form, the checks unchanged, no Save, Revert, Reset, unsaved lines or launch checkbox); no Reset for a source without a default; no launch checkbox without launch settings; the Secrets panel naming the source's `.env`
- `src/app_setup/ui/config_page.py` — new: `config_page(model)`, exported from `app_setup.ui`
- `tests/test_config_file.py`, `tests/test_launch.py` — new; `tests/test_app.py` (bare cases), `tests/test_autostart.py` (the file rule), `tests/test_folder.py` (`env_path`), `tests/ui/test_panels.py` (read-only), `tests/ui/test_config_page.py` — new; `tests-e2e/test_panels_in_browser.py` (a config app; an app running a file)
- `specs/app.md`, `specs/config-folder.md`, `specs/autostart.md`, `specs/secrets.md`, `specs/ui.md`, `specs/config-file.md`, `specs/_index.md` — the specs' text and statuses; `AGENTS.md` (the project map), `README.md` (the source)
