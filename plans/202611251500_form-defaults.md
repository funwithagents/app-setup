# The form: one rule for defaults

**Status:** Done

Implements `specs/ui.md` ("The form"): a field not set shows its default greyed, a value the user set shows white and is saved, for every kind of field. Found trying the demos: an unset number showed its default as a white value, which looked set but was not saved.

## Scope

- `src/module_setup/ui/form.py` — numbers drawn as text boxes (the default as placeholder; the range in the hint); an unset checkbox says the default applies.
- `src/module_setup/ui/panels.py` — the line above the form states the rule.
- `tests/ui/test_panels.py` — an unset number and text field are empty with the default greyed; set ones show their value; the checkbox's hint.
- `specs/ui.md`.

## Steps

1. Draw numbers as text boxes; `coerce` already reads a number back from text and writes a value equal to the default as absent.
2. The checkbox's hint, the legend, the spec, the test.
