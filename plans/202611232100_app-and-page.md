# The app and its page

**Status:** Done

Implements `specs/app.md`, `specs/config-folder.md`, `specs/secrets.md`, `specs/session.md` and `specs/ui.md`: what an app declares, the model behind its page, its folder, its secrets, its sessions, and the page itself behind the `ui` extra.

## Scope

- `src/module_setup/app.py` — `App`, `Section`, `AppModel`, `Problem`, `SetupItem`, `InstallError`
- `src/module_setup/folder.py` — `ConfigFolder`, `Settings`, `default_folder`
- `src/module_setup/secrets.py` — `SecretStore`, `parse_env`, `format_env`
- `src/module_setup/session.py` — `SessionRunner`, `SessionContext`, `SessionState`
- `src/module_setup/form.py` — the form as data and its edits
- `src/module_setup/ui/` — `form.py` (gradio form), `page.py` (`build_page`, `launch`), `report.py` (Markdown)
- `pyproject.toml` — the `ui` extra (gradio 6), in the dev group
- `tests/fakes.py` and one test file per module, `tests/ui/` for the page
- `AGENTS.md`, `README.md`, `specs/_overview.md`, `specs/_index.md`

## Steps

1. The gradio-free parts, each with its tests: the form model, the folder, the secrets, the session runner.
2. `AppModel`, over a fake library implementing the contract.
3. The page: the form drawn inside `gr.render` (redrawn on a change of structure only), the three tabs, the timer, `launch`.
4. Tests of the reports and of the form drawn into a real page.
5. A live run of a page over the fake library, driven through gradio's client: load, check, test, start, save refused while running, stop.

## Verification

`uv run ruff check .`, `uv run ruff format .`, `uv run pyright`, `uv run pytest` all pass (147 tests). The form's behaviour in a browser (typing, switching module, the list picker) was not exercised by a test: gradio's client cannot drive per-browser state.
