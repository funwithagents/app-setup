# Continuous integration

**Status:** In progress

Implements `specs/ci.md`: the verification gate run by GitHub Actions on every pull request and push to `main`. Leaves out a release workflow.

## Scope

- `.github/workflows/ci.yml` — `check` (lint, format, types), `fast-tier` on Linux, macOS and Windows, `browser` (the panels in headless Chromium) on Linux.
- `pyproject.toml`, `uv.lock` — a `browser` dependency group with Playwright, locked, not synced by default.
- `tests-e2e/support.py`, `tests-e2e/test_panels_in_browser.py` — `no_browser`: a missing Playwright or Chromium skips, or fails with `MODULE_SETUP_E2E_REQUIRE_BROWSER=1`.
- `specs/ci.md`, `specs/testing.md` (its open question settled), `specs/_index.md`, `AGENTS.md` (the map's `.github/workflows/` row, the commands).

## Steps

1. Lock Playwright in a `browser` group; make a missing browser a failure on request.
2. Write the workflow.
3. Run it on the pull request and fix what a platform shows.

## Verification

The workflow's own run on its pull request: every job green. Locally: `uv run ruff check .`, `uv run ruff format --check src tests tests-e2e`, `uv run pyright`, `uv run pytest`, `uv run pytest tests-e2e -rs`.
