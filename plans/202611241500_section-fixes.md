# Setup panel fixes found in the tts-engine demo

**Status:** Done

Implements changes to `specs/app.md`, `specs/ui.md`, `specs/module-contract.md` and `specs/secrets.md`, found by trying the first app built on the panels: an extra can be installed while its section's config still has problems; switching module drops the old module's own fields; the checks follow each change of the form's structure; `*` is explained; the Secrets panel shows a `.env` value the shell shadows and the `.env`'s other variables.

## Scope

- `src/module_setup/app.py` — `check_setup`: a section with problems reports its extras from `required_extras` and the installed packages' metadata (`_extra_item`), so **Install missing extras** works before the config is right.
- `src/module_setup/form.py` — `select_branch` drops every field of the old module, keeping only those common to every module.
- `src/module_setup/ui/panels.py` — the checks run, and the output is cleared, on each change of `revision` (page load included); `on_load` no longer computes them. A line says what a field's `*` means.
- `src/module_setup/secrets.py`, `src/module_setup/ui/report.py` — `SecretVariable.in_file`/`shadowed`, `SecretStore.file_names`; the secrets report's shadowed source and the `.env`'s other variables.
- `tests/test_app.py`, `tests/test_form.py`, `tests/test_secrets.py`, `tests/ui/test_report.py`, `tests/ui/test_panels.py`, `tests-e2e/test_panels_in_browser.py` — the above.
- `specs/app.md`, `specs/ui.md`, `specs/module-contract.md` — the behaviour.

## Steps

1. Report the extras of a section with problems.
2. Drop the old module's fields on a switch.
3. Run the checks on each redraw.
4. Say what `*` means above the form.
5. The Secrets panel shows a `.env` value the shell shadows, and lists the `.env`'s other variables by name (`SecretVariable.in_file`/`shadowed`, `SecretStore.file_names`; `specs/secrets.md`, `specs/ui.md`).

## Verification

`uv run ruff check .`, `uv run ruff format --check src tests tests-e2e`, `uv run pyright`, `uv run pytest`, `uv run pytest tests-e2e -rs` (with Playwright).

The deadlock it removes: with a module whose required field is filled from a voice list (`options`), and the list needing the module's extra, the config had a problem, so `check_setup` was not asked, so the extra was not reported, so **Install missing extras** had nothing to install, and the list could not be loaded.
