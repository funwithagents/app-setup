# `probe`, the contract's seventh function

**Status:** Done

Implements `specs/module-contract.md` ("`probe`"): the function that runs a config for real, once, on request. Only its place in the contract is module-setup's to build here; the Test button that calls it belongs to the UI spec.

## Scope

- `src/module_setup/contract.py` — `probe` in `SetupContract`; `check_contract` refuses a contract object lacking any of the seven functions
- `tests/test_contract.py` — the reference contract gains `probe`; a contract without it is a breach

## Steps

1. Add `probe(config) -> dict` to the protocol.
2. `check_contract` starts by checking that the seven names are callable, and raises `ContractViolation` naming the absent ones. It does not call `probe`: what it does depends on the machine.
3. Tests.
